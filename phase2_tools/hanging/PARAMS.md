# 吊り下げ形の生成手順（v5: 立体感を残す比率、2026-11-03）

入力: nike2223_web.blend → 出力: nike2223_hanging.blend / export/kit_hanging.glb

## 目標値
`amabo/JPESC Kit Viewer.blend`（配布物）から寸法の比率だけを計測した。
同梱の Readme に「無断での再配布・二次利用禁止」とあるため、メッシュ・形状データは一切取り込んでいない。

| 項目 | 目標 | v5 の結果 |
|---|---|---|
| 袖込みの全幅 | 0.61m | 0.63m |
| 半袖の角度（水平から下向き） | 53〜54° | 51〜52° |
| 胴体の幅（脇より下） | 0.35〜0.40m | 0.35〜0.39m |
| 胴体の厚み | 0.19〜0.21m | 0.17〜0.21m |
| 丈 | 0.72m | 0.69m |

## 手順
1. 胴体 `stage1_torso.py`（v2）
   `{"gradual":true,"depth_top":0.75,"ramp_top":0.0,"ramp_bot":0.30,"widen":0.25,"depth":0.75,"strip":0.015,"strip_x":0.19,"goal":0.3,"quality":8,"mass":0.15,"bend":1.0,"pin_stiff":1.0,"frames":40,"rest":"flat"}`
   - 着用形の丸みを残し、前後の厚みだけ 0.75倍にする
   - 周長を保つための横への広げは 25% だけ適用する
   - 肩上端を固定して、重力で軽く垂らす
2. 袖 `stage2_sleeves.py`（シミュレーションなし）
   - 半袖: `{"follow_all":true,"rot_deg":16,"blend":0.05,"depth":0.85}`
   - 長袖: `{"follow_all":true,"rot_deg":38,"blend":0.07,"depth":0.85}`（Mesh_0052 は追従させる）
3. 襟 `stage3_collars.py`（胴体の変形を、近傍16点の逆距離加重で転写）

検証結果: 全縫い目のずれは 0.000mm。面構成とUVは元と同一。

## 長袖（v6, 2026-11-03）
`bend_sleeve.py` → `push_out.py`
- 長袖は、肩の付け根から袖の軸に沿ってなめらかな弧で曲げ、体の横をほぼまっすぐ（外向き6°）下ろす
  `{"tilt_deg":6,"bend_start":0.03,"bend_len":0.14,"seam_blend":0.04,"depth":0.85}`
- 残った胴体とのめり込みは、高さごとに袖全体を外へずらして解消する（余裕 6mm）
- 結果: 胴体の内側に入る頂点 22（最大 0.4cm、脇の縫い目付近のみ）

## 厚み（v9, 2026-11-04）前後をもう少し薄く（現行）
`thin_depth.py pos_L5_FINAL.json pos_T80_FINAL.json 0.8`（v8 の形状から、Blender なしで頂点位置だけを変換）
- 各高さでの胴体の前後中央（1cm ごと、±3cm で平均）を中心に、全メッシュ（胴体・袖・襟）の前後を 0.8 倍にする
- 胴体の厚み：0.19〜0.21m → 0.15〜0.17m 程度（全体の最大 0.216m → 0.181m）。幅・丈・袖の角度は変えない
- 同じ関数で動かすので、縫い目は閉じたまま（元で一致していた 2672 組の差は最大 0.08mm、元の差以下）。同じ高さの前後の並び順も保つので、めり込みは増えない
- ハンガーはビューアがシャツの形を測って作るので、自動で薄い肩に合う
- v8 は `nike2223_hanging_v8_L5.blend` / `kit_hanging_v8_L5.glb` としてバックアップ

## 長袖（v8, 2026-11-03）参考写真「吊るした長袖ユニフォーム（ラグラン袖・リブ袖口）」に合わせて作り直し
`bend_sleeve.py` → `push_out.py`（余裕 6mm）
`{"tilt_deg":3,"bend_start":0.01,"bend_len":0.14,"seam_blend":0.04,"depth":1.0,"flat_x":0.8,"flat_z":1.15,"flat_s0":0.02,"flat_s1":0.14,"cuff_taper":0.78,"cuff_len":0.10}`
- 肩はなだらかなラグランの曲線（14cm かけて曲げる）。袖は胴体に沿ってほぼまっすぐ（外向き 3°）
- 断面は正面から見て 0.8倍・前後 1.15倍（v7 より太め）
- 袖口の手前 10cm で断面を 0.78倍まで絞り、リブ袖口の締まりを出す
- 検証: 縫い目のずれ 0.01mm 以下、胴体の内側に入る頂点 2（最大 1.1mm）
- v7 は `nike2223_hanging_v8_L3.blend` としてバックアップ

## 長袖（v7, 2026-11-03）参考写真「吊るした長袖Tシャツ」に合わせて作り直し
`bend_sleeve.py` → `push_out.py`（余裕 6mm）
